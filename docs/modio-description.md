# Ghostline Quest Core

A shared foundation for Cyberpunk 2077 quest mods.

Install Ghostline Quest Core when another mod lists it as a requirement. It lets compatible quest mods start through a common system while each mod supplies its own story and gameplay.

## Getting started

1. Install and enable **Ghostline Quest Core**.
2. Install and enable the quest mods you want to play, following their individual requirements.
3. Load your save and return to normal gameplay.

The core sends a phone message saying **Ghostline Quest Core active. Installed quest packs can now start.** It appears once per save, so it will not repeat every time you load the game.

Each quest mod decides when its content becomes available. Check that mod's description for any level requirements, starting locations or other conditions.

You do not need to visit V's H10 apartment or enter console commands. The core does not require Cyber Engine Tweaks, REDscript or the PC ArchiveXL plugin.

## Included content

The core provides quest startup and its activation message. Install compatible quest mods for playable content. Keep the core enabled while playing mods that require it, and use the core version those mods specify.

## Troubleshooting

If the activation message does not arrive, check that the core is installed and enabled, then return to normal gameplay. A save that has already received the message will not receive it again.

If the core message arrives but a quest does not start, check that quest's starting conditions and requirements. Other mods replacing the same game startup resources can conflict with the core. Report the installed mod versions and whether the problem also occurs with the core and affected quest installed on their own.

Keep a separate save before changing or removing quest mods. Follow each quest's removal guidance; disabling a mod does not erase its saved quest progress.
